# 商机热榜与跨平台比价路线图

本目录集中管理 Fork 后新增的商机功能。按模块开发、测试和回滚；现有客服、发货和商品发布功能沿用上游结构。

## 1. 数据基础 `data`

- 搜索结果区分未知指标与真实零值，记录数据来源、采集时间和失败状态。
- 按租户、规则、商品保存历史快照；首次采集只建立基线。
- 采集失败不覆盖成功快照，控制账号请求频率。

## 2. 近期热榜 `trends`

- 按关键词、类目、价格、地区建立监控规则。
- 用近 7 天有效快照的浏览和想要增量估算热度，公开评分依据与数据覆盖率。
- 区分新上架与热度上升；数据不足时不冒充真实成交榜。

## 3. 跨平台比价 `pricing`

- 统一报价字段：平台、链接、品牌、型号、规格、成色、价格、运费、起订量、阶梯价、采集时间及来源。
- 分开展示闲鱼二手挂牌价、拼多多新品到手价和 1688 指定采购量下的单件含运成本。
- 先核对同款规格；匹配不确定时仅显示相似商品，不计算确定价差。
- 数据接口采用可替换适配器；取得正式授权前，允许保存有来源链接的人工报价。

## 4. 推送与运维 `notifications`

- 复用现有通知渠道，增加商机日报和阈值提醒。
- 按用户、规则、商品和日期去重；保留执行与投递日志。
- 没有新结果时保持安静，失效报价明确标注。

## 交付顺序

数据正确性 → 快照与监控 → 可解释热榜 → 定时推送 → 比价核心 → 拼多多和 1688 正式接口。每一阶段在独立分支验证后合入 `main`；密钥只放部署环境。
